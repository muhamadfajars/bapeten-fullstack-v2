================================================================
PANDUAN PENGGUNAAN APLIKASI BAPETEN — ASISTEN EVALUASI PERIZINAN
================================================================

Aplikasi ini digunakan oleh evaluator perizinan BAPETEN untuk melakukan
penelaahan dan pencocokan dokumen permohonan izin secara otomatis berbasis AI.

PERSYARATAN:
1. Laptop menggunakan sistem operasi Windows 10 atau Windows 11.
2. Laptop sudah terhubung ke jaringan VPN kantor BAPETEN.

CARA PENGGUNAAN:
1. Pastikan VPN BAPETEN sudah dalam kondisi AKTIF (TERHUBUNG).
2. Klik ganda (double-click) file:
      Buka_Evaluator.bat
3. Aplikasi web akan otomatis terbuka di browser (Google Chrome / Edge)
   pada alamat http://localhost:8001/.
4. Anda dapat langsung mengunggah dokumen dan mengevaluasi permohonan.
   (Setiap evaluator/tab memiliki nomor permohonan unik mandiri dan tidak akan tertukar).

CARA MENUTUP APLIKASI:
Jika Anda sudah selesai mengevaluasi dokumen dan ingin menutup koneksi:
- Cukup klik ganda (double-click) file:
      Tutup_Evaluator.bat

CATATAN KEAMANAN:
- File 'bapeten_key' adalah kunci enkripsi khusus evaluator dan tidak
  memerlukan input kata sandi. Jangan menghapus atau memindahkan file tersebut.
- Jalur koneksi ini hanya membuka akses ke web evaluator dan tidak memiliki
  akses ke terminal maupun sistem internal server.
